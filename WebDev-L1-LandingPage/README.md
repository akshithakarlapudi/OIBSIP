RecipeFinder – Landing Page

About the Project

RecipeFinder is a responsive food and recipe landing page developed as part of the Oasis Infobyte Web Development Internship.

Technologies Used

- HTML5
- CSS3

Features

- Navigation bar with Home, Features, About and Contact links
- Attractive hero section with food background image
- RecipeFinder feature cards
- About section
- Contact footer
- Hover effects
- Responsive mobile-friendly design

Project Structure

- index.html – Website structure
- style.css – Website styling

How to Run

1. Download the project.
2. Open the project folder in VS Code.
3. Open index.html in Google Chrome.

- Organization: Oasis Infobyte
